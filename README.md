# BCA Notes Portal

A dark-themed, terminal-inspired study hub for BCA students — built to make finding notes, resources, and roadmap guidance feel less like digging through scattered PDFs and more like using an actual tool.

🔗 **Live site:** [a4ace1.github.io/a4ace_1](https://a4ace1.github.io/a4ace_1/)

![Status](https://img.shields.io/badge/status-active-brightgreen)
![Made with](https://img.shields.io/badge/made%20with-HTML%2FCSS%2FJS-crimson)

---

## ✨ Features

- **Terminal aesthetic UI** — dark background, glassmorphism panels, crimson accent highlights
- **Resource library** — organized notes and materials with in-page preview modals (no need to download just to check a file)
- **After BCA Roadmap** — a dedicated section mapping out career paths after graduation (higher studies, jobs, certifications, etc.)
- **Typing Speed Test** — a built-in mini-game to kill time productively
- **BCA Quiz** — quick self-test quiz covering core BCA subjects
- **Floating Music Player** — persistent lo-fi/study music player that follows you across pages
- **Live Visit Counter** — real visitor count powered by [CounterAPI](https://counterapi.dev)

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (custom glassmorphism styling), JavaScript
- **Hosting:** GitHub Pages
- **Visit tracking:** CounterAPI

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/a4ace1/a4ace_1.git
   cd a4ace_1
   ```
2. Open `index.html` directly in a browser, or serve it locally:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`

No build tools or dependencies required — it's a static site.

---

## 📖 Usage

- Browse notes by semester/subject from the resources section
- Click any resource card to preview it before downloading
- Check the **After BCA Roadmap** tab for guidance on what comes next
- Take a break with the typing test or quiz
- Music player keeps playing as you navigate between sections
